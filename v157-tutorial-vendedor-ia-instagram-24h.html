✓ Por que social seller não escala

Com a API do Claude conectada ao Manychat, você tem um atendente que responde a qualquer hora, nunca cansa, nunca esquece o script e melhora conforme você ajusta o prompt. O custo é fixo e previsível. A disponibilidade é total.

O que você vai ter no final: directs respondidos automaticamente, leads qualificados sem intervenção humana e vendas fechadas enquanto você dorme — tudo pelo custo de uso da API, sem CLT, sem encargos, sem drama.

1 Gerar a chave de API no Claude Console

Acesse console.anthropic.com e faça login na sua conta Anthropic. No menu lateral, clique em API Keys e depois em Create Key.

Dê um nome para identificar essa integração — algo como "Manychat Instagram" — e confirme. O sistema vai gerar um código que começa com sk-ant-. Copie agora: você só vai ver esse código uma vez. Se fechar a janela antes de copiar, vai precisar gerar uma nova chave.

Dica: guarde a chave em algum lugar seguro antes de sair da tela. Um arquivo de texto local já resolve.

2 Conectar a API no Manychat

Com a chave copiada, abra seu Manychat e vá em Configurações → Integrações. Localize o Claude na lista de integrações disponíveis e clique para conectar.

Cole a chave de API no campo indicado e confirme. Em menos de dois minutos, o Claude já aparece como uma ação disponível dentro dos seus fluxos de automação.

Verificação: se a conexão funcionar, o status vai aparecer como "Conectado" ao lado do nome do Claude na tela de integrações. Se der erro, confira se copiou a chave completa, sem espaços no início ou no final.

3 Criar o fluxo de atendimento automático

No Manychat, crie uma nova automação com o gatilho Incoming Message (para responder qualquer direct) ou Keyword Trigger (para responder quando alguém comentar uma palavra específica, como "API", e mandar direct automático).

Dentro do fluxo, adicione um bloco de Ação, selecione o Claude como a ação e configure o comportamento via System Prompt. Esse prompt é onde você define o tom, o escopo do que o Claude pode responder e qual é o objetivo da conversa — qualificar o lead, fechar venda ou redirecionar para WhatsApp.

  • Ative o fluxo e coloque em Live
  • Teste mandando um direct para o seu próprio perfil
  • Ajuste o prompt até o tom parecer humano e alinhado com sua marca
Prompt mínimo para começar: "Você é [seu nome ou nome do atendente], assistente de vendas do [seu negócio]. Responda de forma amigável e direta. Seu objetivo é entender o que o lead precisa e direcioná-lo para [link de compra / agendamento]. Responda em no máximo 3 frases curtas."

✓ O que muda depois que está no ar

Nenhum direct fica sem resposta, nem de madrugada nem no domingo. Leads que antes esfriavam por falta de retorno rápido passam a ser atendidos em segundos. E você para de depender de uma pessoa para manter o atendimento funcionando.

O próximo nível é afinar o prompt com base nas conversas reais: quais objeções aparecem mais, quais perguntas o Claude não sabe responder, onde os leads abandonam. Com essas informações, você ajusta e o sistema fica progressivamente mais eficiente sem custo adicional.

Resultado real: atendimento automático, humanizado e disponível 24h — sem contratar ninguém, sem pagar salário, sem depender de horário comercial. A integração leva menos de 10 minutos para configurar e funciona indefinidamente.
