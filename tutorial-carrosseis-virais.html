1 Crie um Projeto no Claude

Entre no claude.ai e clique em Projects na barra lateral esquerda. Crie um projeto novo e dê um nome tipo Carrosséis Instagram.

Por que usar Projects? O Claude vai lembrar das suas preferências de marca, público e estilo em todos os carrosséis que você criar dentro desse projeto.

2 Configure as instruções do projeto

Clique em Set project instructions e cole o prompt de configuração abaixo. Ele define as regras de layout, design e estrutura que o Claude vai seguir em todos os carrosséis.

Prompt de configuração — copie e cole:

Layout Best Practices:
1. Content must never overlap the progress bar. Use padding-bottom: 52px on any slide content that extends to the bottom.
2. User-uploaded images may be JPEGs despite .png extension. Always check the actual file format.
3. Test every slide visually before export.

Design Principles:
1. Every slide is export-ready
2. Light/dark alternation — creates visual rhythm
3. Heading + body font pairing
4. Brand-derived palette
5. Progressive disclosure — progress bar fills
6. Last slide is special — no arrow, full progress bar, clear CTA
7. Consistent components across all slides
8. Content padding clears UI
9. Iterate fast — show preview, fix specific slides

3 Mande imagens se tiver

Antes de pedir o carrossel, envie as imagens que quer usar. O Claude vai incluir elas automaticamente nos slides certos. Se não tiver imagens, ele cria sem.

4 Use os prompts de início

Pra começar a gerar, use um prompt assim:

Exemplos de prompts:

• Build a carousel highlighting the 5 biggest mistakes beginners make when launching a business

• Create a carousel showing how Claude AI helps marketers get better results

• Design a carousel to promote my product launch using this website as reference: [url]

• Convert this blog post into an engaging carousel: [cole o texto]

5 Detalhe seu conteúdo com esse prompt

Pra resultados ainda melhores, use esse modelo antes de pedir o carrossel:

TEMA: [nome do tema]
HOOK: [gancho principal do slide 1]
PÚBLICO: [quem vai ver]
CTA: [o que você quer que a pessoa faça no final]
IMAGENS: [descreve o que você tem]
SLIDES: [quantidade — ex: 8 slides]

✓ Resultado esperado

Você sai desse tutorial conseguindo criar carrosséis prontos pra postar ou vender, com design profissional, em minutos. Sem precisar de designer, sem agência, sem gastar nada além do plano do Claude.

Dica final: Dê feedback específico por slide — "slide 3 com menos texto e mais contraste". Quanto mais específico, melhor o resultado. Peça sempre uma versão mais curta depois — carrosséis menores performam melhor.
