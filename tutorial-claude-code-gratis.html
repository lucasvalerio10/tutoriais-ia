✓ O que é o 9Router

Alguém no GitHub criou uma ferramenta chamada 9Router que fica entre o seu editor de código e os provedores de IA. O que ela faz é simples: quando o seu limite do Claude acaba, ela muda você automaticamente para o próximo provedor disponível — Gemini, Kimi, GLM — sem você precisar fazer nada.

Depois que os limites dos provedores principais acabam, ela continua roteando para modelos totalmente gratuitos. A sessão de programação nunca para.

Analogia: é como um piloto automático para seus créditos de IA. Sempre procurando a melhor opção gratuita, sempre te mantendo no ar, sem interrupção.

1 Como funciona na prática

Você instala o 9Router, conecta as chaves de API dos provedores que quer usar, e pronto. A partir daí, tudo é automático.

  • Limite do Claude esgotou? Vai pra Gemini.
  • Gemini chegou no limite? Vai pro Kimi.
  • Kimi chegou? Vai pra GLM ou outro modelo gratuito disponível.

Sem troca manual, sem editar configuração, sem tempo parado esperando o limite renovar. A configuração inicial leva alguns minutos e depois é transparente pra sempre.

Link: 9router.com

2 Compatibilidade — funciona com tudo

Essa é a parte mais importante: o 9Router não é exclusivo do Claude Code. Ele funciona com praticamente qualquer ferramenta de programação com IA que você já usa.

  • Claude Code — claude.ai
  • Cursor — cursor.com
  • Codex — chatgpt.com/codex
  • Antigravity — antigravity.google

Uma única configuração cobre toda a sua pilha de desenvolvimento. Mesmo que você troque de ferramenta ao longo do dia, o 9Router continua roteando pra modelos gratuitos em segundo plano.

Para quem é isso: devs independentes, estudantes, e qualquer pessoa que já bateu no limite de API no meio de uma sessão e ficou sem conseguir trabalhar. Orçamento zero, programação sem parar.

3 Como instalar

O repositório está disponível no GitHub. O processo é:

  • 1. Acesse 9router.com e siga o link pro repositório
  • 2. Instale o pacote seguindo as instruções do README
  • 3. Conecte as chaves de API dos provedores que quiser usar (Gemini, Kimi, GLM são gratuitos com cadastro)
  • 4. Configure sua ferramenta preferida para apontar pro 9Router como proxy
Tempo de setup: em torno de 5 a 10 minutos na primeira vez. Depois disso, nunca mais precisa mexer.

✓ Por que isso muda o jogo

Antes do 9Router, quando o limite acabava você tinha três opções: pagar mais, esperar o limite renovar, ou parar de trabalhar. Agora você tem uma quarta opção: continuar sem gastar nada.

Para quem está construindo projetos pessoais, estudando, ou testando ideias, isso tira o principal obstáculo financeiro de usar IA no desenvolvimento do dia a dia.
