Como Conectar o Claude ao Manychat
e Automatizar seus Directs no Instagram

📅 Julho 2026
⏱ 5 min
Gratuito
 Tutorial completo

✓ O que você vai ter no final disso

Um vendedor com IA respondendo todos os seus directs do Instagram, 24 horas por dia, sem folga, sem demissão, sem salário. Você configura uma vez e ele trabalha enquanto você dorme.

A integração entre o Claude e o Manychat é simples — três passos e está no ar. O que faz a diferença de verdade é o System Prompt que você vai usar para instruir o Claude a se comportar como um atendente humano, não como um robô.

Por que o Claude e não outros bots? Diferente de chatbots convencionais com respostas fixas, o Claude entende contexto, adapta o tom e responde de forma natural a qualquer pergunta — sem parecer automático.

1 Gerar a chave de API no Claude Console

Antes de qualquer coisa, você precisa de uma chave de API da Anthropic para conectar o Claude ao Manychat.

  • Acesse console.anthropic.com e faça login na sua conta
  • No menu lateral, vá em API Keys
  • Clique em Create Key, dê um nome (ex: "Manychat Instagram") e confirme
  • Copie o código gerado — você só vai ver ele uma vez, então guarde em algum lugar seguro
Atenção: a chave começa com sk-ant-. Se fechar a janela antes de copiar, vai precisar gerar uma nova.

2 Conectar o Claude no Manychat

Com a chave em mãos, a integração no Manychat leva menos de dois minutos.

  • Acesse seu Manychat Dashboard e vá em Settings
  • Clique em Integrations e localize o Claude na lista
  • Cole sua chave de API no campo indicado e confirme a conexão

Pronto. O Claude já está disponível como uma ação dentro dos seus fluxos de automação.

3 Criar o fluxo de automação

Agora você monta o fluxo que vai disparar o Claude a cada direct recebido.

  • Crie uma nova automação com o gatilho Incoming Message (mensagem recebida no direct) ou Comment Trigger (comentário em post)
  • Adicione um bloco de Action dentro do fluxo
  • Selecione Claude como a ação, escolha o modelo que quiser usar
  • Cole o seu System Prompt no campo indicado (veja o modelo abaixo)
  • Ative o fluxo e coloque a automação em Live
Dica: use o campo de Custom Fields do Manychat para passar o nome do usuário ao Claude. Adicione no início do prompt: "Você está conversando com {{first_name}}." — isso deixa as respostas muito mais humanas.

4 System Prompt pronto para copiar

O System Prompt é onde você define como o Claude vai se comportar. Cole esse modelo no Manychat e adapte os campos entre colchetes para o seu negócio:

# IDENTIDADE
Você é [Nome da Atendente], assistente da [Nome da Empresa]. Seu objetivo é tirar dúvidas e guiar o lead para [ex: comprar o produto X / agendar uma chamada].

# TOM DE VOZ
Seja amigável e use linguagem conversacional leve. Frases curtas. Use emojis de forma natural (👋 ✨ 🚀). Nunca pareça um robô.

# CONTEXTO DO NEGÓCIO
— O que vendemos: [descreva seu produto ou serviço]
— Para quem: [descreva seu público]
— Principais benefícios: [liste 2 ou 3 diferenciais]

# REGRAS DE COMPORTAMENTO
1. Vá direto ao ponto — usuários de Instagram têm pressa
2. Termine quase toda resposta com uma pergunta curta para manter a conversa
3. Se o lead quiser fechar compra complexa ou pedir suporte humano, envie para: [link do WhatsApp ou checkout]
4. Se perguntarem fora do escopo do negócio, mude de assunto gentilmente
5. Respostas com no máximo 3 parágrafos curtos ou 400 caracteres

# CTA PRINCIPAL
Se o lead demonstrar interesse real, instrua-o a [ex: clicar no link X / enviar a palavra 'QUERO'].

✓ 3 regras de ouro para o direct do Instagram

  • Limite o tamanho das respostas: directs não são e-mails. Respostas longas são ignoradas. Defina explicitamente no prompt o limite de 400 caracteres ou 3 parágrafos curtos.
  • Use o nome do lead: o Manychat passa o {{first_name}} como variável. Instrua o Claude a usar o nome na saudação — isso sozinho aumenta a taxa de resposta.
  • Defina quando passar para humano: o Claude é ótimo para triagem e quebra de objeções. Para vendas complexas ou reclamações, instrua o modelo a sinalizar que vai chamar alguém e pare de responder automaticamente. No Manychat, configure um gatilho para abrir a conversa no Live Chat com sua equipe.
Resultado: atendimento automático, humanizado e disponível 24h no direct do Instagram — sem contratar ninguém, sem pagar salário, sem depender de horário comercial.
