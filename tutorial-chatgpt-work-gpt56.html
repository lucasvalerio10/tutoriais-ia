✓ O que é o ChatGPT Work e por que é diferente

A OpenAI reorganizou o ChatGPT em torno de três modos de trabalho. O Chat para perguntas rápidas do dia a dia. O Codex para programação. E o ChatGPT Work — um agente completamente novo que executa ações nos seus aplicativos e arquivos, mantém contexto entre prompts, permanece em um projeto por horas se necessário, e transforma uma meta em um entregável concreto.

Todos os três estão reunidos no novo app ChatGPT para desktop. O ChatGPT Work também está disponível na web e em dispositivos móveis. A diferença central é que o Work é alimentado pelo GPT-5.6 — a família de modelos mais recente da OpenAI, disponível em três níveis: Sol para raciocínio profundo, Terra para equilíbrio entre custo e qualidade no dia a dia, e Luna para tarefas rápidas e leves.

Acesso: ChatGPT Work está disponível nos planos Pro, Enterprise e Edu. Os planos Plus e Business estão sendo lançados progressivamente. No app desktop, os três modos (Chat, Work e Codex) estão disponíveis em todos os planos, incluindo o Free — para Windows e Mac globalmente.

1 Como começar — criar um projeto no ChatGPT Work

Acesse chatgpt.com/work no navegador ou abra a aba Work no app desktop. Na interface, clique em Choose Project no canto inferior esquerdo, selecione New project e dê um nome para o que você vai construir.

Escolha o modelo GPT-5.6 que faz sentido para a complexidade da tarefa. Para análises simples e tarefas rápidas, o 5.6 Sol Light já é suficiente. Para raciocínio profundo e tarefas de múltiplas etapas, use o 5.6 Sol completo.

A interface mostra a aba Work ativa, o nome do projeto na parte inferior do chat e o seletor de modelo. Você envia arquivos pelo ícone de + na área de mensagem — CSV, PDF, planilhas, documentos — e eles ficam disponíveis em todo o projeto.

Diferença do ChatGPT normal: no modo Work, o contexto persiste entre prompts dentro do projeto. Você não precisa reexplicar o que está fazendo a cada mensagem. O agente lembra dos arquivos, das decisões e do estado do projeto enquanto trabalha.

2 Criação de sites com ChatGPT Work Sites

Uma das aplicações mais poderosas do ChatGPT Work é a criação de sites reais — não mockups, não protótipos estáticos, mas aplicações web funcionais publicadas e acessíveis por qualquer pessoa.

Antes, criar uma landing page exigia lidar com hospedagem, deploy, autenticação e banco de dados. Com o ChatGPT Sites, você descreve o que quer, o Work constrói em HTML, JavaScript e CSS, testa a interface internamente e publica com um link ao vivo. O processo inteiro acontece dentro do chat.

  • Descreva o tipo de site que precisa — formulário, calculadora, app interativo, landing page
  • O Work gera o código e pede permissão para visualizar o site antes de publicar
  • Clique em Allow for this chat para que ele teste e refine automaticamente
  • O link publicado fica em seu-projeto.editor.chatgpt.site
Exemplo real: um preditor de churn de clientes bancários — o Work construiu o formulário com inputs para 10 variáveis do cliente, conectou ao modelo de machine learning treinado na mesma sessão, e publicou uma interface que retorna a probabilidade de saída em milissegundos. Zero linha de backend escrita pelo usuário.

3 Geração de artefatos — o diferencial real do GPT-5.6

Para confiar na IA para trabalho profissional de verdade, ela precisa gerar artefatos sem erro — documentos, planilhas, slides, PDFs, relatórios com gráficos. O GPT-5.6 deu um salto específico nessa capacidade, e o Work foi construído para aproveitá-la.

O painel Outputs no canto superior direito do chat guarda todos os arquivos gerados durante o projeto. Você não precisa copiar nada — o Work vai salvando automaticamente conforme executa cada etapa.

  • Relatórios em PDF com gráficos, tabelas e análise narrativa
  • CSV limpos depois de auditoria e limpeza de dados
  • Código Python reprodutível com pipelines completos de machine learning
  • Slides e documentos estruturados a partir de contexto desorganizado
  • Arquivos ZIP com o projeto inteiro organizado em pastas
Como usar: jogue um contexto desorganizado no Work — notas, dados brutos, arquivos de referência — conecte às suas ferramentas externas pelo Google Drive ou outros plugins, e peça o entregável final. Ele divide em etapas menores, executa cada uma e monta o resultado.

4 Exemplo completo — ciência de dados do zero no navegador

O caso de uso mais demonstrativo do que o ChatGPT Work realmente faz é um projeto completo de ciência de dados — sem instalar nada, sem abrir terminal, sem gerenciar ambientes.

Fazendo upload de um dataset real (como o Churn_Modelling.csv do Kaggle), o Work com GPT-5.6 executa um fluxo completo em sequência:

  • Auditoria: inspeciona linhas, colunas, valores ausentes, duplicatas e risco de data leakage — e entrega um relatório estruturado em markdown
  • Limpeza: remove colunas irrelevantes (identificadores), trata variáveis categóricas, preserva o dataset original sem modificação
  • Visualizações: gera gráficos de distribuição de churn, taxas por segmento, boxplots e mapa de calor de correlação — tudo em um PDF de 14 páginas com interpretação de cada gráfico
  • Modelagem: treina Gradient Boosting, Random Forest, Regressão Logística e Dummy Classifier com split estratificado 80/20, valida apenas no conjunto de treino, avalia no conjunto de teste intocado
  • Resultado: Gradient Boosting com ROC-AUC 0.871, PR-AUC 0.719 e F1 0.605 — selecionado automaticamente como melhor modelo
Tempo total: o projeto inteiro — do dataset bruto ao app de previsão publicado — foi concluído dentro do ChatGPT Work sem sair do navegador, sem instalar bibliotecas e sem escrever código manualmente.

5 Integração com ferramentas externas

O ChatGPT Work se conecta a serviços externos via plugins. No painel inferior da interface, clique em Plugins para ver e conectar integrações disponíveis — incluindo Google Drive, que permite ao Work ler e gravar arquivos diretamente nos seus drives sem precisar fazer download e upload manual.

Com tarefas agendadas, o Work mantém projetos em andamento mesmo quando você está offline — por exemplo, transformar novas mensagens do Teams ou Slack em documentos atualizados e compartilhar mudanças com o time automaticamente.

Comparação com setups locais: VS Code + extensões + notebooks espalhados + conflitos de versão + ambientes diferentes por projeto — isso some. Você fica em um só lugar e o projeto cresce ao redor. Para quem quer ir de dados brutos a um demo funcional sem tocar no terminal, ChatGPT Work com GPT-5.6 é o caminho mais direto disponível hoje.

✓ Quando usar o Work vs Chat vs Codex

  • Chat: perguntas rápidas, escrita, brainstorming, explicações — qualquer coisa que não precise de arquivo ou múltiplas etapas
  • Codex: programação interativa, debug, revisão de código, desenvolvimento com contexto de repositório
  • Work: tarefas ambiciosas e demoradas — análise de dados, criação de sites, geração de relatórios completos, projetos que precisam de contexto persistente entre vários prompts e entregáveis reais para baixar ou publicar
Acesse: chatgpt.com/work — disponível agora nos planos Pro, Enterprise e Edu. Planos Plus e Business em lançamento progressivo.
